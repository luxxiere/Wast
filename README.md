# Wast

Легковесный инструмент на Go для быстрого развертывания Xray (VLESS-Reality) с автоматическим выпуском SSL, Nginx-заглушкой, поддержкой ссылок-подписок и удобным CLI.

---

## Быстрая установка

Для установки на сервер выполните команду:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/luxxiere/Wast/main/install.sh)
```

---

## Возможности

* **Высокая производительность и автономность** — написан на **Go**, компилируется в единый статический бинарник без внешних рантайм-зависимостей.
* **Автоматический SSL** — получение и продление сертификатов Let's Encrypt через Certbot.
* **Автоопределение локации** — страна и флаг сервера определяются автоматически при установке и вшиваются в конфигурацию.
* **HTTP/HTTPS Заглушка** — Nginx на порту 80 с автоматическим редиректом на 443 и локальным fallback на 8443.
* **Ссылки подписок** — генерация base64-подписок для удобного подключения в любых клиентах (v2rayN, v2rayNG, SingBox, Happ и др.).
* **BBR** — опция включения алгоритма BBR при установке для максимальной скорости и стабильности.
* **CLI интерфейс** — управление через понятные команды.

---

## Управление через CLI

```bash
# Добавить пользователя (при пустом имени будет сгенерировано случайное из 8 символов)
wast add user
wast add user alex

# Удалить пользователя по ID
wast delete user 1

# Показать всех пользователей
wast list user

# Проверить статус служб и нагрузку сервера
wast status

# Справка по командам
wast help

# Полное удаление Wast с сервера
wast uninstall
```
