# Wast

Легковесный инструмент на Go для быстрого развертывания Xray (VLESS-Reality) с автоматическим выпуском SSL, Nginx-заглушкой, поддержкой распределенных мульти-нод, ссылок-подписок и удобным CLI.

---

## Быстрая установка

Для установки на сервер выполните команду:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/luxxiere/Wast/main/install.sh)
```

При запуске установщик предложит выбрать тип сервера:
- **1) Основной сервер (Master)** — управление клиентами, база данных SQLite, выдача подписок, API для синхронизации нод и собственная локация подключения.
- **2) Нода (Node)** — дополнительная локация в другой стране, автоматически получающая клиентов с основного сервера.

---

## Возможности

* **Мульти-ноды и распределенные локации** — подключение любого количества нод в разных странах через защищенный API.
* **Автоматическое обновление подписок** — при добавлении новой ноды все клиенты мгновенно получают доступ к новой локации в своей единой ссылке-подписке.
* **Защита Cloudflare** — основной домен подписок и управления (`example.com`) можно закрыть проксированием Cloudflare, полностью скрывая реальный IP основного сервера от DDoS-атак и сканирования.
* **Вывод прямых VLESS-ссылок** — команда `wast list users` выводит как ссылку-подписку, так и готовые прямые VLESS-ссылки для каждой подключенной локации с эмодзи флагов.
* **Автоматический SSL** — получение и продление сертификатов Let's Encrypt через Certbot (совместимо с Cloudflare).
* **Автоопределение и настройка локации** — страна и флаг сервера определяются автоматически при установке с возможностью задать свое название.
* **HTTP/HTTPS Заглушка** — Nginx на порту 80 с автоматическим редиректом на 443 и локальным fallback на 8443.
* **BBR** — опция включения алгоритма BBR при установке для максимальной скорости и стабильности.
* **CLI интерфейс** — управление через понятные команды.

## Управление через CLI

### На основном сервере (Master):

```bash
# Добавить пользователя (при пустом имени будет сгенерировано случайное из 8 символов)
wast add user
wast add user alex

# Удалить пользователя по ID
wast delete user 1

# Показать всех пользователей (ссылка-подписка + VLESS-ссылки всех локаций)
wast list users

# Получить данные для подключения новой ноды
wast connect

# Список всех подключенных локаций и нод
wast nodes

# Удалить ноду по ID
wast delete node 2

# Проверить статус служб и нагрузку сервера
wast status

# Справка по командам
wast help

# Полное удаление Wast с сервера
wast uninstall
```

### На ноде (Node):

На нодах управление клиентами не требуется — служба `wast-node` автоматически синхронизирует пользователей с основным сервером в реальном времени.

```bash
# Проверить статус ноды и связь с основным сервером
wast status

# Полное удаление Wast с ноды
wast uninstall
```

## Подключение новой ноды (Пошагово)

1. На **основном сервере** выполните:
   ```bash
   wast connect
   ```
   Команда выдаст временный URL подключения и секретный ключ (действительны 30 минут):
   ```text
   URL подключения: https://example.com/connect/a8f1b2c3d4e5
   Секретный ключ:  wsec_9fa81c04d8b2e173...
   ```
2. На **новом сервере** запустите установщик:
   ```bash
   bash <(curl -fsSL https://raw.githubusercontent.com/luxxiere/Wast/main/install.sh)
   ```
3. Выберите `2) Нода`, укажите домен ноды (например, `de.example.com`), введите URL подключения и секретный ключ.
4. Нода подключится, заберет всех текущих клиентов, а основной сервер автоматически обновит подписки всех пользователей, добавив новую локацию!
