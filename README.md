# Wast

Легковесный скрипт для быстрого развертывания Xray (VLESS-Reality) с автоматическим выпуском SSL, Nginx-заглушкой, поддержкой ссылок-подписок и удобным CLI-интерфейсом.

---

## Быстрая установка

Для установки на сервер используйте команду:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/luxxiere/Wast/main/install.sh)
```

---

## Возможности

* **Автоматический SSL** — получение и продление сертификатов Let's Encrypt через Certbot.
* **HTTP/HTTPS Заглушка** — Nginx на порту 80 с автоматическим редиректом на 443 и локальным fallback на 8443.
* **Ссылки подписок** — генерация base64-подписок для удобного подключения в любых клиентах (v2rayN, v2rayNG, SingBox, Happ и др.).
* **BBR** — опция включения алгоритма BBR при установке для максимальной скорости и стабильности.
* **Удобный CLI** — управление через команду `wast` (добавление/удаление клиентов, мониторинг состояния системы).
* **Автономность** — работает исключительно на стандартной библиотеке Python 3, без сторонних `pip`-пакетов.

## Требования

* ОС: **Ubuntu 24.04**
* Домен, направленный на IP сервера (A-запись)
* Открытые порты `80/tcp` и `443/tcp`
